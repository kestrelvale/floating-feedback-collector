## 1. 参数提取规则与多租户隔离规范

在两份提示词开头，均设有统一结构化的【参数提取与配置区】。AI Agent 接单后，遵循以下规则自适应绑定参数：

- **线上模式 (Online)**:
  - `PROJECT_NAME`: 当前项目的业务标题（例如 `"甄晨生鲜O2O配送系统"`、`"正杰全球聘人力资源系统"`），用于中台顶栏大标题展示。
  - `PROJECT_KEY`: 当前项目的唯一租户标识（例如 `"o2o-shipping"`、`"zhengjie-hrm"`），用于服务端数据库分库隔离与工单前缀。
  - `ONLINE_URL`: 线上完整访问根地址。支持任意形式：
    - 纯 HTTPS 域名 (无端口): `https://admin.zhenchenmart.top`
    - 纯 IP 带非标端口: `http://43.139.67.247:10128`
    - 纯 IP 不带端口: `http://43.139.67.247`
    - 子路径反代: `https://mycompany.com/o2o-service`
    Agent 自动执行 URL 归一化，严禁强行拼接 `:8888` 等错误端口！
  - `LOCAL_PORT`: 本地排障中台独立辅助端口（自动寻空分配，绝不占用业务开发端口）。
- **本地模式 (Local)**:
  - `PROJECT_NAME` & `PROJECT_KEY`: 本地项目标题与租户 Key。
  - `LOCAL_PORT`: 本地开发服务端口（自动寻空分配）。

ONLINE_URL=$(echo "$ONLINE_URL" | sed 's:/*$::')
if [[ ! "$ONLINE_URL" =~ ^https?:// ]]; then
  if [[ "$ONLINE_URL" =~ ^([0-9]{1,3}\.){3}[0-9]{1,3} ]] || [[ "$ONLINE_URL" =~ ^localhost ]]; then

find_free_port() {

    p=$((p + 1))
  done
  echo "$p"
}
