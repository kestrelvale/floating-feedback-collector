## 1. 参数定义与自适应提取机制

在两份提示词开头，均设有统一的【参数提取与配置区】。AI Agent 接单后，遵循以下规则自适应绑定参数：

- **线上模式 (Online)**:
  - `ONLINE_DOMAIN`: 线上服务器域名或公网 IP。优先读取提示词头部声明；若未填写，指示 Agent 自动从当前项目的部署脚本（如 `deploy.sh`、Nginx 配置、环境变量 `REMOTE_HOST`）中自动探测提取。
  - `ONLINE_PORT`: 线上服务对外通信端口。优先读取提示词头部声明；未填写默认根据协议取对应端口（如 `8888` 或 `23333`）。
  - `LOCAL_PORT`: 本地中台调试端口。默认 `8888`，Agent 自动探测本地端口，若被占用自动顺延至 `8889`~`8899`。
  - `REMOTE_URL`: 组合出的远程完整 URL：`http://${ONLINE_DOMAIN}:${ONLINE_PORT}`。
- **本地模式 (Local)**:
  - `LOCAL_PORT`: 本地开发服务端口。默认 `8888`，Agent 自动探测本地空闲端口，后方全部命令统一复用此端口。

## 4. 双模式关键参数对照表

| 参数标识符 | 变量引用 | 线上模式 (Online) 作用 | 本地模式 (Local) 作用 | 参数自动解析与复用逻辑 |
| :--- | :--- | :--- | :--- | :--- |
| `ONLINE_DOMAIN` | `${ONLINE_DOMAIN}` | 远程云端 API 寻址与图片访问主机 | *(无需配置，自动置空)* | 优先读取头部声明；未填写时由 Agent 从当前项目部署配置探测 |
| `ONLINE_PORT` | `${ONLINE_PORT}` | 远程云端服务对外通信端口 | *(无需配置，自动置空)* | 优先读取头部声明；未填写默认取 `8888` 或 `23333` |
| `LOCAL_PORT` | `${LOCAL_PORT}` | 本地中台调试与展示端口 (默认 8888) | 本地独立 Node API 运行与中台端口 | 优先取 8888；Agent 自动探测端口冲突并自动顺延 |

| `GIT_REPO` | `${GIT_REPO}` | 官方权威代码仓库 | 官方权威代码仓库 | 锁死源: `https://github.com/kestrelvale/floating-feedback-collector.git` |

## 5. 质量验收门禁规范 (Definition of Done)

无论使用线上模式还是本地模式，Agent 执行完成后必须满足以下质量门禁方可宣告交付：

1. **零白屏与代码完整性**: 目标项目打开任意页面无 JS 运行时异常，控制台 0 报错；
2. **SDK 样式与手势正常**: 页面右下角成功渲染 42px 磨砂圆球，手势拖拽吸边与滚动避让流畅；
3. **真实快照捕获**: 点击反馈能正常抓取当前视口 DOM 快照并生成缩略图与全屏 Lightbox；
4. **单真理源数据隔离**: 线上模式只与云端通信，本地模式绝对零外部网络外发，两模式数据互不污染；
5. **按需动作驱动**: 中台无盲目定时轮询，空闲期 0 网络负荷，只在打开、提单、结案、手动刷新时产生请求；
6. **参数全链路一致**: 交付卡中的中台体验地址必须与实际绑定的 `${LOCAL_PORT}` 或 `${REMOTE_URL}` 完全一致。
