# 悬浮反馈收集器 · 三种部署模式与详细配置指南

## 1. 纯本地模式 (Local Only)

### 适用于：
- 局域网离线演示、本地快速打样、无公网服务器或敏感保密项目。

### 工作流：
1. 前端用户在页面点击「🐞 问题反馈」提交问题；
2. SDK 自动生成 DOM 截图并存入浏览器 `localStorage`，同时异步推送到本地 Node.js 进程 `http://127.0.0.1:8888/api/feedback/save`；
3. 本地启动服务后，可在浏览器访问 `http://127.0.0.1:8888/feedback-dashboard.html` 查看大盘；
4. AI Agent 本地运行，通过 Stdio MCP 读取项目根目录下的 `data/feedback_database.json` 与 `data/snapshots/` 直接读取物理图片分析。

### 核心配置：
- `feedback-collector.js`:
  ```javascript
  const RUNTIME_MODE = 'local';
  const DEFAULT_REMOTE_URL = 'http://127.0.0.1:8888';
  ```
- MCP 环境变量 (`.mcp.json`):
  ```json
  {
    "mcpServers": {
      "feedback-collector": {
        "command": "node",
        "args": ["mcp/feedback-mcp-server.js"],
        "env": { "REMOTE_SERVER_URL": "http://127.0.0.1:8888" }
      }
    }
  }
  ```

## 2. 纯线上模式 (Online Only)

### 适用于：
- 项目已全量部署在云端公网服务器（如腾讯云/阿里云/AWS），测试人员与甲方面向公网域名进行验收与提单。

### 工作流：
1. 前端用户在公网 URL 访问页面，提交反馈直接 POST 到线上服务接口；
2. 线上 Node.js / Nginx 反代统一持久化到云端磁盘 `/data/snapshots/` 与 `feedback_database.json`；
3. 项目团队与管理人员直接打开线上 `http://your-domain.com/feedback-dashboard.html` 查看实时工单。

### 核心配置：
- `feedback-collector.js`:
  ```javascript
  const RUNTIME_MODE = 'online';
  const DEFAULT_REMOTE_URL = 'http://your-domain.com:port';
  ```

---

## 3. 本地+线上混合模式 (Hybrid / Dual-Sync - 推荐)

### 适用于：
- 企业级敏捷交付最佳实践：测试人员在云端真机体验提单，开发人员/AI Agent 在本地环境中进行代码修复与排障验证。

### 工作流：
1. **端侧快速存盘**: 用户提单时优先写入本地存储，即使网络波动也绝不丢失数据，网络通畅时静默推送到云端；
2. **大盘全局汇聚**: 任何端（本地或线上）打开 Dashboard 时，会自动扫描未同步工单并增量汇聚上云；
3. **MCP 跨端拉取与视觉排障**: 本地 AI Agent 接收到云端反馈后，MCP 会自动向云端发起 HTTP 请求，将远程快照下载到本地 `data/snapshots/{id}.png`，返回绝对物理路径给 Agent，Agent 通过 `view_image` 查看真实界面进行精准修复；
4. **双向自动回写**: 本地调用 `resolve_feedback` 结案后，状态与修复说明自动回写推送到云端，云端 Dashboard 实时变绿已解决。

### 核心配置：
- `feedback-collector.js`:
  ```javascript
  const RUNTIME_MODE = 'hybrid';
  const DEFAULT_REMOTE_URL = 'http://your-server-domain:port';
  ```
